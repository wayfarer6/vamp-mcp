# VAMP icon

Publisher: `wayfarer6`. Extension ID: `wayfarer6.vamp-mcp`.

[vscode-extension/icon.png](../vscode-extension/icon.png) is the icon used in the VSIX, the GitHub README and the extension README. It was generated with `image_gen` and combines a bat with a virtual-machine monitor. The source prompt is preserved below.

Generation prompt:

> Use case: logo-brand. Asset type: square VS Code Marketplace application icon for VAMP (Virtual Agent Machine Platform), software for VM automation by AI agents and RPA. Create one polished, original compact mascot emblem: a friendly geometric bat with spread wings framing a small virtual-machine monitor at its center. Clean flat shapes, strong silhouette, balanced symmetry, readable at 32 pixels, generous safe margin. Dark navy rounded-square tile, restrained violet and teal accents, subtle modern depth, professional developer-tool identity. No words, no letters, no watermark, no existing brand logos. Square 1024 by 1024.

Marketplace delivery: the generated icon is resized to 512×512 and saved as an optimized PNG, below the 1024 KB upload limit. The extension build checks that limit before packaging.
