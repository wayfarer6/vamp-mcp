VAMP: make a recording for an AI agent

Run INSIDE the guest VM, not on the host.
1. Confirm guest resolution 1920x1080, OS scale 100%, browser zoom 100%.
2. Open Desktop/RPA-Recorder (the desktop may be localized/redirected).
   Windows: Start-Recorder.cmd. Debian/Ubuntu GNOME X11: start-recorder.sh.
3. Record -> perform task -> Stop -> Download. Save recordings/my_task.py.
   Never record passwords, certificate private keys or CAPTCHA solutions.
4. Run: python prepare-recording.py recordings/my_task.py
   Debian/Ubuntu: python3 prepare-recording.py recordings/my_task.py
5. Give the AI VM name + guest OS + absolute recording path, and the desired
   success condition. The .handoff.json records the path/hash without replay.

A guest-only file path is NOT automatically readable by a host MCP server.
Transfer the Python recording to the host and give its host path, or agree
on a supported retrieval route. Existing SPICE static conversion is available.
VirtualBox recorded replay conversion is still pending; its input tools work,
but do not treat a SPICE URI as a VirtualBox VM connection.

The AI can inspect the Python text without executing it, create Robot/Python
RPA steps and update guest pixel coordinates from fresh screen evidence.
Prefer Win+R for Windows app startup and Alt+F2 on GNOME, rather than desktop icons.

Windows requires a valid license. After installation, activate Windows yourself
in Settings -> System -> Activation. VAMP does not include a license or bypass activation.

Every guest user login: VAMP's display hook requests 1920x1080 again.
Windows: %LOCALAPPDATA%\VAMP\display\result.json
GNOME: ~/.local/share/vamp/display/result.json
If verified=false, install/update the display driver/Guest Additions, reboot,
and sign in again. The hook never starts the recorder or records keys by itself.
